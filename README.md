# Meu Projeto de Engenharia de Software I

Este é o projeto para a disciplina, cobrindo Gitflow, TDD e Makefiles.

## Estrutura
* `/src`: Código fonte (.cpp)
* `/include`: Arquivos de cabeçalho (.hpp)
* `/test`: Código de teste
* `/doc`: Documentação
* `/bin`: Arquivos compilados (ignorados pelo .gitignore)
